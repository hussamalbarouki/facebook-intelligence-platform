توثيق تفاعلي كامل
أنشئ API Key ثم افتح Swagger، اضغط Authorize، ضع المفتاح، وبعدها استخدم Try it out على أي مسار.
مثال PHP
\$ch = curl_init('https://YOUR-DOMAIN/v1/read/page?ref=nasa');
curl_setopt_array(\$ch, [
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => ['X-API-Key: YOUR_API_KEY'],
  CURLOPT_TIMEOUT => 180
]);
\$result = json_decode(curl_exec(\$ch), true);
curl_close(\$ch);
يدعم /v1/run/{operation} جميع أوامر المحرك المسموحة، و/v1/jobs للعمليات الطويلة، و/v1/capabilities لاكتشاف الوظائف.
